# bowntouDisplay — 빛의 갑옷

구글폼 응답을 **실시간으로 읽어 동틀녘 하늘에 띄우는** 웹앱입니다.
[UnderwoodTextVisualizer](https://github.com/MechEnginee/UnderwoodTextVisualizer)와 같은 방식으로 동작하며,
화면을 나누지 않고 하나의 질문만 보여줍니다.

> **질문** — 내가 버려야 할 어둠의 일은?
>
> ¹¹ 또한 너희가 이 시기를 알거니와 자다가 깰 때가 벌써 되었으니 이는 이제 우리의 구원이 처음 믿을 때보다 가까웠음이라
> ¹² 밤이 깊고 낮이 가까웠으니 그러므로 우리가 어둠의 일을 벗고 빛의 갑옷을 입자
> — 로마서 13:11–12

## 화면 구성
- **동틀녘 하늘** — 위는 별이 반짝이는 깊은 밤, 아래로 갈수록 보랏빛·주홍빛으로 밝아지고
  지평선에서 해가 떠오르며 빛줄기가 천천히 돕니다. 왼편 하늘에는 샛별이 빛납니다.
- **응답(어둠의 일)** — 밤하늘 영역에 떠다닙니다. 같은 답이 반복되면 더 크고 굵어집니다.
- **빛의 갑옷을 입은 병사들** — 투구·흉갑·갑옷 치마를 두르고 창을 곧게 세운 병사들이
  발을 맞춰 해를 향해 행진합니다. 발이 땅을 디딜 때마다 빛이 번지고,
  걸음은 이동 거리와 동기화되어 발이 미끄러지지 않습니다.
- **말씀** — 지평선 아래 땅 위에 로마서 13:11–12 이 표시됩니다.

## 설정 (⚙️)
| 항목 | 설명 |
|------|------|
| Google API 키 / 스프레드시트 ID / 탭 이름 | 연결할 구글시트 |
| 폴링 간격(초) | 기본 5 |
| 표시할 열 | “열 불러오기” 후 선택 (‘어둠’이 들어간 열을 자동 선택) |
| 질문 문구 | 기본 “내가 버려야 할 어둠의 일은?” |
| 화면 단어 개수 · 글자 크기 · 떠다니는 속도 · 단어 굵기 | 단어 표시 |
| 병사 크기 · 병사 수 · 행진 속도 | 행진 애니메이션 |
| 질문·말씀 크기 | 상단 질문과 하단 말씀 글자 크기 |

설정은 브라우저(localStorage)에 저장됩니다. 시트 준비(공유 설정, API 키 발급 등)는
UnderwoodTextVisualizer README 와 동일합니다.

## 사용 팁
- 화면을 **더블클릭**하면 테스트 단어가 뜹니다(15초 후 사라짐).
- 시트에서 행을 지우면 다음 폴링 때 화면에서도 사라집니다.
- 로컬 확인: `python3 -m http.server 8000` 후 `http://localhost:8000/` (API 키 리퍼러에 추가 필요)
- `prefers-reduced-motion` 환경에서는 병사들이 제자리에 서 있습니다.
